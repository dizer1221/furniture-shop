# Интернет-магазин мебели «Уют» (учебный проект)

Демонстрационный интернет-магазин мебели: каталог, корзина и оформление заказа. Магазин вымышленный, заказы не принимаются.

## Возможности
- каталог товаров с фильтром по категориям и фотографиями
- корзина: добавление, изменение количества, удаление, итоговая сумма
- корзина сохраняется в браузере при обновлении страницы
- форма заказа с проверкой полей
- заказ отправляется в Telegram с готовым текстом сообщения

## Технологии
HTML, CSS, JavaScript (без библиотек)

## Запуск
Откройте файл index.html в браузере.

## Фотографии
Фото взяты с бесплатных стоков (Unsplash, Pexels), авторы указаны на страницах источников.
